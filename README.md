# AI Exposure-Management Teaching Sandbox — Research Scaffold

This repository reproduces the data analysis, figures, and manuscript for:

**Teaching Exposure Management Without Production Data: A Real-World KEV/EPSS
Analysis for an AI Cybersecurity Sandbox**

The project analyzes public CISA Known Exploited Vulnerabilities (KEV) data and
FIRST EPSS current scores to motivate a privacy-preserving AI cybersecurity
education sandbox (PERS). The manuscript is formatted for the **CCSC
(Consortium for Computing Sciences in Colleges)** conference template.

This is a **research scaffold and descriptive analysis**, not a production
security tool. The paper does **not** claim measured classroom learning gains,
production security improvement, or deployment success; those claims would
require a later controlled course pilot and institutional review. The framing is
vendor-neutral.

## Contents

- `scripts/analyze_kev_epss.py` — joins KEV and EPSS, computes threshold
  capture/miss rates, ransomware and due-window statistics, vendor/CWE counts,
  and writes an HTML report plus `reports/analysis_summary.json`.
- `scripts/build_paper_assets.py` — generates the paper figures (Pillow),
  the LaTeX table fragments, and `paper/summary_macros.tex`.
- `data/raw/` — public source snapshots (CISA KEV JSON, FIRST EPSS CSV).
- `data/processed/` — the joined KEV/EPSS dataset.
- `reports/` — generated analysis outputs and source notes.
- `paper/` — CCSC LaTeX source, figures, tables, and a compiled preview
  (`main_preview.pdf`). See `paper/README_OVERLEAF.md`.
- `PROJECT_INSTRUCTIONS.md` — authoring, submission, data-boundary, and
  release-readiness notes.

## Reproduce

Use Python 3.11+.

```bash
python3 -m pip install -r requirements.txt
python3 scripts/analyze_kev_epss.py       # regenerates the joined dataset + summary
python3 scripts/build_paper_assets.py      # regenerates figures, tables, and macros
```

Verified snapshot (regenerated by the scripts): **1,631** KEV entries, **100.0%**
EPSS coverage, **328** ransomware-linked entries, median EPSS **0.543**, median
due window **21** days.


The paper is double-blind-ready: it defaults to an anonymized author block and
exposes a one-line `\anontrue`/`\anonfalse` switch for the camera-ready version.
**Confirm all author names, affiliations, and emails before the camera-ready
submission.**

## Data policy

Public cyber-threat intelligence only:

- CISA KEV JSON
- FIRST EPSS current-scores CSV
- Public framework references (NIST CSF, MITRE ATT&CK, NIST AI RMF)

No production telemetry, student records, endpoint or identity logs, or private
vendor-customer data are present.

## Key result

EPSS-only thresholds miss many CISA KEV vulnerabilities: in the analyzed
snapshot, EPSS `>= 0.50` captures 51.7% of KEV entries (misses 787) and EPSS
`>= 0.90` captures 26.9% (misses 1,193). This supports teaching multi-signal
exposure reasoning — confirmed exploitation, predicted exploitation, asset
exposure, criticality, control gaps, and deadlines together — rather than
relying on any single score.
